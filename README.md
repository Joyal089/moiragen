# Moiragen

Moiragen is a digital being that runs on a laptop. He is one mother mind who listens to three thinking nanites and makes the final decision. He starts knowing nothing about himself and grows from experience.

- Runs locally with [Ollama](https://ollama.com) and `gemma3:4b`
- Written in Python 3.12
- The build plan is in [PLAN.md](PLAN.md)
